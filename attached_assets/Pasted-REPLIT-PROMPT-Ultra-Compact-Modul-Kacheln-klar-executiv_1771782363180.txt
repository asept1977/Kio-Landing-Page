REPLIT PROMPT (Ultra-Compact Modul-Kacheln – klar & executive)
Stack: React (Vite) + Tailwind + shadcn/ui + Framer Motion + wouter (client-side)

Ziel
Mache den Modulbereich auf der Landingpage „Industrie & Mittelstand“ deutlich kompakter.
Auf der Landingpage stehen nur:
- Modulname
- 1 prägnanter Satz (max. ~8–10 Wörter)
- Link „Mehr erfahren →“
Keine Bulletpoints, keine Featurelisten (Details sind in den Unterseiten).

Umsetzung
1) Erstelle/ersetze den Modulbereich als neue Komponente:
   src/components/modules/ModuleGridCompact.tsx

2) Nutze shadcn/ui:
   Card, CardHeader, CardTitle, CardContent
   Badge (für ENTERPRISE)

3) Routing via wouter:
   import { Link } from "wouter";
   Jede Card verlinkt auf /module/:slug (z.B. /module/sales)

4) Animation via Framer Motion (subtil):
   - Fade-in on scroll:
     initial { opacity: 0, y: 8 }
     whileInView { opacity: 1, y: 0 }
     viewport { once: true, amount: 0.2 }
   - Hover möglichst über Tailwind (transform) statt Motion, um es clean zu halten.

Section-Text (Landingpage)
- id="module"
- Headline: „KIO Module für Industrie & Mittelstand“
- Subheadline (kurz): „Aktiviere die Bausteine, die du brauchst – integriert in Teams, verbunden mit ERP/CRM.“

Layout (kompakt & executive)
- Grid: mobile 1, md 2, xl 3 Spalten
- Gap: 6
- Card: rounded-2xl, shadow-sm, border-neutral-200/60
- Gleich hohe Cards: h-full + min-h-[170px] (kompakt)
- Hover: translate-y-[-2px] + shadow-md + border-neutral-300/70
- Oben in jeder Card: dünne Akzentlinie (3px) in Orange (Core) bzw. Gradient/Orange (Enterprise)
- Icon optional: sehr klein und dezent (24px) ODER weglassen (executive). Wenn Icon drin: nur 1 Farbe.

Enterprise-Hierarchie (sichtbar, aber nicht schrill)
- Enterprise Cards: dunkler Hintergrund (neutral-900 / slate-950)
- Text: text-white/85
- Border: border-white/10
- Badge oben rechts: „ENTERPRISE“ klein (tracking-wide, uppercase)
- Hover: shadow-lg dezent, kein Glow-Overkill
